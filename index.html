Rules of ATLAS

1. Word Chain: Next answer must start with the last letter of the previous word (e.g. AFRICA → AMERICA → AUSTRALIA).

2. Speed Bonus: Answer faster to get up to +5 bonus points.

3. 3 Passes: Each player has 3 passes to skip without penalty.

4. Unknown Words: If a word is not recognized, players vote whether to accept it.

5. Elimination: 3 strikes eliminates a player. Last survivor wins!
